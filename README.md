## 🤖 GIWA ECOSYSTEM AUTOMATION BOT

An automation bot built with JavaScript / Node.js for interacting with the GIWA Ecosystem.

## 📦 Project Structure

```
Giwa-Ecosystem-Automation-Bot/
├── index.js
├── .env
├── package.json
└── README.md
```

## 🚀 How to Use

### 1. Install dependencies

```bash
git clone https://github.com/yumidara/Giwa-Ecosystem-Automation-Bot.git
cd Giwa-Ecosystem-Automation-Bot
npm install
```

### 2. Setup konfigurasi

```bash
nano .env
```

Then edit .env file:

```env

PRIVATE_KEY=0x.....

```

### 3. run

```bash
node index.js

```

---

## ⚠️ Security Warning

- ❌ **DO NOT** commit the .env file to GitHub
- ❌ **DO NOT** bagikan private key ke siapapun
- ✅ Use a separate wallet specifically for the bot
- ✅ Always test with a small amount firstu
